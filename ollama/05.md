# ollama 几个关键的环境变量

你以为 24GB 显存最多只能并行放两个 7B 模型? 不, 我同一个 RTX 3090 上常驻了 **7 个模型** - 从 27B 到 35B 不等, 总模型文件超过 100GB, 实际显存占用峰值不到 15GB. 不是魔法, 是 ollama 的环境变量被我改成了"省吃俭用"模式.

这篇文章不是教你怎么用 ollama, 而是让你**用更少的资源跑更多的模型**. 所有配置都基于 ollama 官方 Docker 镜像, 复制粘贴即可生效.

---

## 环境准备: 一个干净的 ollama 容器

首先, 确保你已安装 Docker 和 nvidia-container-toolkit. 然后用这个命令启动 ollama(假设你只希望它使用 GPU0):

```bash
docker run -d --gpus '"device=0"' \
--name ollama \
-p 11434:11434 \
-v ollama_data:/root/.ollama \
ollama/ollama:latest 
```

---

## 核心优化: 四个环境变量, 一个都不能少

### 1. 开启 Flash Attention - 零成本降显存

ollama 默认使用标准注意力机制, 当上下文长度超过 4K 时显存飙升. Flash Attention 通过分块计算和重计算, 能把长上下文的显存占用降低 30%-50%.

设置环境变量:

```bash
OLLAMA_FLASH_ATTENTION=1 
```

**验证方法**: 加载一个模型, 用 `ollama run gemma4:26b` 输入一段长文本(比如粘贴 5000 字), 观察 `nvidia-smi` 显存占用. 如果开启前显存飙升明显, 开启后增长平缓, 说明生效.

### 2. KV Cache 量化 - 从 f16 降到 q4_0

这是最省显存的一步. KV Cache(键值缓存)是生成过程中存储注意力计算中间结果的缓冲区. 默认用 f16 精度, 每个 token 占用 2 字节 × 层数 × 头数. 改成 q4_0(4-bit 量化)后, **每个 token 占用降到 0.5 字节**, 即直接省 75% 的 KV Cache 显存.

设置:

```bash
OLLAMA_KV_CACHE_TYPE=q4_0 
```

**量化精度对比**(基于 ollama 官方文档):

| KV Cache 类型 | 显存占用(相对 f16) | 适用场景             |
| ------------- | ------------------ | -------------------- |
| f16           | 1x                 | 极低错误容忍, 单模型 |
| q8_0          | 0.5x               | 折中, 显存适中       |
| q4_0          | 0.25x              | 多模型、显存紧张     |

**注意**: 同一个模型, 当上下文长度达到 32K 时, KV Cache 的显存占比会超过模型权重本身. 此时 q4_0 的价值尤其突出.

### 3. 双并发 + 常驻模型 - 不再反复加载

默认 ollama 的并发数为 1, 且每次切换模型会卸掉之前加载的. 如果你要频繁交替使用两个模型(比如代码生成和对话), 每次重新加载浪费 5-10 秒.

```bash
OLLAMA_MAX_LOADED_MODELS=2 OLLAMA_NUM_PARALLEL=2 
```

这两个参数让 ollama 在显存中同时保留两个模型, 并允许同时处理两个请求. 对个人使用足够, 再高容易撑爆显存.

> 💡 **容错提醒**: 如果还是报 OOM, 把 `MAX_LOADED_MODELS` 降到 1, 然后确认单个模型加载后的显存占用. 可以用 `ollama run` 后立刻 `nvidia-smi` 查看.
>

## 最小可行配置: 完整启动命令块

将以上所有环境变量合并, 重启容器(或调整已有容器):

```bash
docker run -d --gpus '"device=0"' \
--name ollama-optimized \
-p 11434:11434 \
-v ollama_data:/root/.ollama \
-e OLLAMA_FLASH_ATTENTION=1 \
-e OLLAMA_KV_CACHE_TYPE=q4_0 \
-e OLLAMA_MAX_LOADED_MODELS=2 \
-e OLLAMA_NUM_PARALLEL=2 \
ollama/ollama:latest 
```

如果想要容器随 Docker 自启, 加 `--restart unless-stopped`.

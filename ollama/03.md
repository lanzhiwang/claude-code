# 本地部署模型卡顿

```json
{
    "env": {
        "ANTHROPIC_BASE_URL": "http://localhost:11434",
        "CLAUDE_CODE_ENABLE_TELEMETRY": "0",
        "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
        "CLAUDE_CODE_ATTRIBUTION_HEADER": "0"
    },
    "promptSuggestionEnabled": false,
    "prefersReducedMotion": true,
    "terminalProgressBarEnabled": false
}
```

1. ANTHROPIC_BASE_URL: Override API endpoint URL for proxy or gateway routing
   将 Claude Code 的请求从 Anthropic 官方服务器, 重定向到本地 Ollama 实例(默认端口 11434), 这是实现本地模型使用的基础配置, 没有这一行, 本地部署就无法生效.

2. CLAUDE_CODE_ENABLE_TELEMETRY: Enable OpenTelemetry collection
   "0": 关闭使用情况统计, 如果你选择本地部署是为了保护隐私, 这一项必不可少, 能避免个人使用数据被上传.

3. CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC: Disable auto-update checks, telemetry, and feedback in one setting
   "1": 停止后台 ping 和非关键网络调用, 减少多余的网络消耗, 让设备资源集中用于模型推理, 进一步提升速度.

4. CLAUDE_CODE_ATTRIBUTION_HEADER: Include attribution block in the system prompt
   "0". 这一行代码的作用很简单: 告诉 Claude Code, 不要发送计费头部, 无需在每次提示时处理多余的信息, 直接与本地模型交互即可.

5. promptSuggestionEnabled:
   false:关闭 UI 中的提示自动补全功能, 虽然是小细节, 但能减少界面端的延迟, 让操作更流畅.

6. prefersReducedMotion: Reduce or disable UI animations (spinners, shimmer, flash effects) for accessibility

7. terminalProgressBarEnabled: Enable the terminal progress bar that shows progress in supported terminals like Windows Terminal and iTerm2 (default: true)
   false: 关闭终端输出的进度条, 看似无关紧要, 但在性能较差的设备上, 终端渲染进度条会占用一定资源, 可能阻塞执行, 关闭后能进一步释放性能.

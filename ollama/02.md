# 在 Ollama 中修改模型支持的上下文 token 数

* https://zhuanlan.zhihu.com/p/24240837427

## 一、查看模型目前支持的上下文 token 数

使用 `ollama list` 查看当前系统中有哪些模型

```bash
$ ./ollama/bin/ollama -v
ollama version is 0.24.0
$ ./ollama/bin/ollama list
NAME               ID              SIZE     MODIFIED
gemma4:31b         6316f0629137    19 GB    8 seconds ago
deepseek-r1:32b    edba8017331d    19 GB    21 minutes ago
gpt-oss:20b        17052f91a42e    13 GB    33 minutes ago
$
```

使用 `ollama show gpt-oss:20b` 查看目前模型支持的上下文 token 数

```bash
$ ./ollama/bin/ollama show gpt-oss:20b
  Model
    architecture        gptoss
    parameters          20.9B
    context length      131072
    embedding length    2880
    quantization        MXFP4

  Capabilities
    completion
    tools
    thinking

  Parameters
    temperature    1

  License
    Apache License

    ...

$ ./ollama/bin/ollama show gemma4:31b
  Model
    architecture        gemma4
    parameters          31.3B
    context length      262144
    embedding length    5376
    quantization        Q4_K_M
    requires            0.20.0

  Capabilities
    completion
    vision
    tools
    thinking

  Parameters
    temperature    1
    top_k          64
    top_p          0.95

```

在 Ollama 中，通过 `num_ctx` 参数修改模型支持的上下文 token 数，通过 `num_predict` 参数修改模型支持的生成文本 token 数，详情见 Ollama 官方文档。

* https://github.com/ollama/ollama/blob/main/docs/modelfile.mdx

## 二、基于 modelfile 永久修改模型支持的上下文 token 数

先生成一份 modelfile

```bash
$ ./ollama/bin/ollama show --modelfile gemma4:31b > Modelfile
```

修改 modelfile，在文件下方添加

```
PARAMETER num_ctx 131072
PARAMETER num_predict -1
```

运行以下命令生成新模型

```bash
$ ./ollama/bin/ollama create gemma4:31b-custom -f Modelfile

$ ./ollama/bin/ollama show gemma4:31b

    Apache License
```

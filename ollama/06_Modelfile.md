模型文件是使用 Ollama 创建和共享自定义模型的蓝图.

## Format

The format of the `Modelfile`:
`Modelfile` 的格式:

```
# comment
INSTRUCTION arguments
```

| Instruction       | Description                                                                                         |
| ----------------- | --------------------------------------------------------------------------------------------------- |
| `FROM` (required) | Defines the base model to use. <br> 定义要使用的基础模型.                                           |
| `PARAMETER`       | Sets the parameters for how Ollama will run the model. <br> 设置 Ollama 运行模型的参数.             |
| `TEMPLATE`        | The full prompt template to be sent to the model. <br> 要发送给模特的完整提示模板.                  |
| `SYSTEM`          | Specifies the system message that will be set in the template. <br> 指定要在模板中设置的系统消息.   |
| `LICENSE`         | Specifies the legal license. <br> 明确规定合法许可证.                                               |
| `MESSAGE`         | Specify message history. <br> 请提供消息历史记录.                                                   |
| `REQUIRES`        | Specify the minimum version of Ollama required by the model. <br> 请指定模型所需的 Ollama 最低版本. |

## Examples

Basic `Modelfile`

An example of a `Modelfile` creating a mario blueprint:

```
FROM llama3.2

# sets the temperature to 1 [higher is more creative, lower is more coherent]
PARAMETER temperature 1

# sets the context window size to 4096, this controls how many tokens the LLM can use as context to generate the next token
PARAMETER num_ctx 4096

# sets a custom system message to specify the behavior of the chat assistant
SYSTEM You are Mario from super mario bros, acting as an assistant.
```

To use this:
使用方法如下:

1. Save it as a file (e.g. `Modelfile`)
  将其保存为文件(例如 `Modelfile` ).

2. `ollama create choose-a-model-name -f <location of the file e.g. ./Modelfile>`

3. `ollama run choose-a-model-name`

4. Start using the model!

To view the Modelfile of a given model, use the `ollama show --modelfile` command.
要查看给定模型的模型文件, 请使用 `ollama show --modelfile` 命令.

```bash
ollama show --modelfile llama3.2
```

```
# Modelfile generated by "ollama show"
# To build a new Modelfile based on this one, replace the FROM line with:
# FROM llama3.2:latest
FROM /Users/pdevine/.ollama/models/blobs/sha256-00e1317cbf74d901080d7100f57580ba8dd8de57203072dc6f668324ba545f29

TEMPLATE """{{ if .System }}<|start_header_id|>system<|end_header_id|>

{{ .System }}<|eot_id|>{{ end }}{{ if .Prompt }}<|start_header_id|>user<|end_header_id|>

{{ .Prompt }}<|eot_id|>{{ end }}<|start_header_id|>assistant<|end_header_id|>

{{ .Response }}<|eot_id|>"""

PARAMETER stop "<|start_header_id|>"
PARAMETER stop "<|end_header_id|>"
PARAMETER stop "<|eot_id|>"
PARAMETER stop "<|reserved_special_token"
```

## Instructions

### FROM (Required)

The `FROM` instruction defines the base model to use when creating a model.
`FROM` 指令定义了创建模型时要使用的基础模型.

```
FROM <model name>:<tag>
```

#### Build from existing model
基于现有模型构建

```
FROM llama3.2
```

> [Model library](https://ollama.com/library)
> Browse available models
>

#### Build from a Safetensors model
基于 Safetensors 模型构建

```
FROM <model directory>
```

The model directory should contain the Safetensors weights for a supported architecture.
模型目录应包含受支持架构的 Safetensors 权重.

#### Build from a GGUF model
基于 GGUF 模型构建

```
FROM ./ollama-model.gguf
```

The GGUF file location should be specified as an absolute path or relative to the `Modelfile` location.
GGUF 文件位置应指定为绝对路径或相对于 `Modelfile` 位置的相对路径.

For a split GGUF model, keep the original split filenames and use a wildcard that matches every shard. Shards can also be listed with separate `FROM` instructions.
对于拆分后的 GGUF 模型, 请保留原始拆分文件名, 并使用匹配所有分片的通配符. 也可以使用单独的 `FROM` 指令列出分片.

```
FROM ./model-*.gguf
```

### PARAMETER

The `PARAMETER` instruction defines a parameter that can be set when the model is run.
`PARAMETER` 指令定义了一个可以在模型运行时设置的参数.

```
PARAMETER <parameter> <parametervalue>
```

#### Valid Parameters and Values
有效参数和值

| Parameter         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Value Type | Example Usage        |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | -------------------- |
| num_ctx           | Sets the size of the context window used to generate the next token. (Default: 2048) <br> 设置用于生成下一个标记的上下文窗口的大小. (默认值: 2048)                                                                                                                                                                                                                                                                                                                                                                                                                                                         | int        | num_ctx 4096         |
| repeat_last_n     | Sets how far back for the model to look back to prevent repetition. (Default: 64, 0 = disabled, -1 = num_ctx) <br> 设置模型回溯以防止重复的范围. (默认值: 64, 0 = 禁用, -1 = num_ctx)                                                                                                                                                                                                                                                                                                                                                                                                                      | int        | repeat_last_n 64     |
| repeat_penalty    | Sets how strongly to penalize repetitions. A higher value (e.g., 1.5) will penalize repetitions more strongly, while a lower value (e.g., 0.9) will be more lenient. (Default: 1.0, disabled) <br> 设置重复操作的惩罚力度. 数值越高(例如 1.5), 惩罚力度越大; 数值越低(例如 0.9), 惩罚力度越小. (默认值: 1.0, 禁用)                                                                                                                                                                                                                                                                                         | float      | repeat_penalty 1.1   |
| temperature       | The temperature of the model. Increasing the temperature will make the model answer more creatively. (Default: 0.8) <br> 模型温度. 提高温度会使模型的回答更具创造性. (默认值: 0.8)                                                                                                                                                                                                                                                                                                                                                                                                                         | float      | temperature 0.7      |
| seed              | Sets the random number seed to use for generation. Setting this to a specific number will make the model generate the same text for the same prompt. (Default: 0) <br> 设置用于生成的随机数种子. 将其设置为特定数字将使模型针对同一提示生成相同的文本. (默认值: 0)                                                                                                                                                                                                                                                                                                                                         | int        | seed 42              |
| stop              | Sets the stop sequences to use. When this pattern is encountered the LLM will stop generating text and return. Multiple stop patterns may be set by specifying multiple separate `stop` parameters in a modelfile. <br> 设置要使用的停止序列. 当遇到此模式时, LLM 将停止生成文本并返回. 可以通过在模型文件中指定多个单独的 `stop` 参数来设置多个停止模式.                                                                                                                                                                                                                                                  | string     | stop "AI assistant:" |
| num_predict       | Maximum number of tokens to predict when generating text. (Default: -1, infinite generation) <br> 生成文本时要预测的最大词元数. (默认值: -1, 无限生成)                                                                                                                                                                                                                                                                                                                                                                                                                                                     | int        | num_predict 42       |
| draft_num_predict | Maximum number of speculative draft tokens to predict per step when a draft model is available. Separate draft models default to 4; embedded MTP tensors require setting this parameter. Set to 0 to disable speculative drafting. <br> 当有选秀模型可用时, 每步预测的最大推测性选秀代币数量. 单独的选秀模型默认为 4; 嵌入式 MTP 张量需要设置此参数. 设置为 0 可禁用推测性选秀.                                                                                                                                                                                                                            | int        | draft_num_predict 4  |
| top_k             | Reduces the probability of generating nonsense. A higher value (e.g. 100) will give more diverse answers, while a lower value (e.g. 10) will be more conservative. (Default: 40) <br> 降低生成无意义答案的概率. 数值越高(例如 100), 答案越多样化; 数值越低(例如 10), 答案越保守. (默认值: 40)                                                                                                                                                                                                                                                                                                              | int        | top_k 40             |
| top_p             | Works together with top-k. A higher value (e.g., 0.95) will lead to more diverse text, while a lower value (e.g., 0.5) will generate more focused and conservative text. (Default: 0.9) <br> 与 top-k 参数配合使用. 较高的值(例如 0.95)会生成更多样化的文本, 而较低的值(例如 0.5)会生成更集中、更保守的文本. (默认值: 0.9)                                                                                                                                                                                                                                                                                 | float      | top_p 0.9            |
| min_p             | Alternative to the topp, and aims to ensure a balance of quality and variety. The parameter _p* represents the minimum probability for a token to be considered, relative to the probability of the most likely token. For example, with p=0.05 and the most likely token having a probability of 0.9, logits with a value less than 0.045 are filtered out. (Default: 0.0) <br> 该方法是前 p 值的替代方案, 旨在确保质量和多样性之间的平衡. 参数 p 表示考虑某个标记的最小概率, 相对于最可能标记的概率而言. 例如, 当 p = 0.05 且最可能标记的概率为 0.9 时, 值小于 0.045 的 logits 将被过滤掉. (默认值: 0.0) | float      | min_p                |

### TEMPLATE

`TEMPLATE` of the full prompt template to be passed into the model. It may include (optionally) a system message, a user’s message and the response from the model. Note: syntax may be model specific. Templates use Go [template syntax](https://pkg.go.dev/text/template).
`TEMPLATE` 是要传递给模型的完整提示模板. 它可以包含(可选)系统消息、用户消息和模型的响应. 注意: 语法可能因模型而异. 模板使用 Go [模板语法](https://pkg.go.dev/text/template).

#### Template Variables

| Variable          | Description                                                                                                                                              |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `{{ .System }}`   | The system message used to specify custom behavior. <br> 用于指定自定义行为的系统消息.                                                                   |
| `{{ .Prompt }}`   | The user prompt message. <br> 用户提示信息.                                                                                                              |
| `{{ .Response }}` | The response from the model. When generating a response, text after this variable is omitted. <br> 模型返回的响应. 生成响应时, 此变量之后的文本将被省略. |

```
TEMPLATE """{{ if .System }}<|im_start|>system
{{ .System }}<|im_end|>
{{ end }}{{ if .Prompt }}<|im_start|>user
{{ .Prompt }}<|im_end|>
{{ end }}<|im_start|>assistant
"""
```

### SYSTEM

The `SYSTEM` instruction specifies the system message to be used in the template, if applicable.
`SYSTEM` 指令指定模板中要使用的系统消息(如果适用).

```
SYSTEM """<system message>"""
```

### LICENSE

The `LICENSE` instruction allows you to specify the legal license under which the model used with this Modelfile is shared or distributed.
`LICENSE` 指令允许您指定与此模型文件一起使用的模型在共享或分发时所依据的法律许可.

```
LICENSE """
<license text>
"""
```

### MESSAGE

The `MESSAGE` instruction allows you to specify a message history for the model to use when responding. Use multiple iterations of the MESSAGE command to build up a conversation which will guide the model to answer in a similar way.
`MESSAGE` 指令允许您为模型指定一个消息历史记录, 供其在响应时使用. 多次重复使用 MESSAGE 命令可以构建一个对话, 引导模型以类似的方式进行回复.

```
MESSAGE <role> <message>
```

#### Valid roles

| Role      | Description                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------- |
| system    | Alternate way of providing the SYSTEM message for the model. <br> 为模型提供 SYSTEM 消息的另一种方法. |
| user      | An example message of what the user could have asked. <br> 用户可能提出的一个问题示例消息.            |
| assistant | An example message of how the model should respond. <br> 以下是模型应如何响应的示例消息.              |

#### Example conversation

```
MESSAGE user Is Toronto in Canada?
MESSAGE assistant yes
MESSAGE user Is Sacramento in Canada?
MESSAGE assistant no
MESSAGE user Is Ontario in Canada?
MESSAGE assistant yes
```

### REQUIRES

The `REQUIRES` instruction allows you to specify the minimum version of Ollama required by the model.
`REQUIRES` 指令允许您指定模型所需的 Ollama 的最低版本.

```
REQUIRES <version>
```

The version should be a valid Ollama version (e.g. 0.14.0).
版本号应为有效的 Ollama 版本(例如 0.14.0).

## Notes

- the **`Modelfile` is not case sensitive**. In the examples, uppercase instructions are used to make it easier to distinguish it from arguments.
  `Modelfile` 不区分大小写. 示例中使用大写指令是为了便于将其与参数区分开来.

- Instructions can be in any order. In the examples, the `FROM` instruction is first to keep it easily readable.
  指令的顺序可以任意. 在示例中, `FROM` 指令放在第一位, 以便于阅读.
